v2s-ios attribution notice

This repository is an iOS-first fork of franklioxygen/v2s:
https://github.com/franklioxygen/v2s

It starts from and retains the expanded runtime language-catalog work in pull request #20, contributed by @oToToT:
https://github.com/franklioxygen/v2s/pull/20
https://github.com/oToToT

This fork adds an iPhone and iPad app with microphone-only capture, equal source and translation layouts for portrait and landscape, transcript and settings views, and iOS project and build configuration. It adds a Traditional Chinese interface and default subtitle output while keeping Simplified Chinese selectable. The original macOS target remains as shared engine and regression coverage.

Local model and runtime notices

Breeze-ASR-26 Core ML assets are fetched separately from:
https://huggingface.co/weiren119/Breeze-ASR-26-coreml-4bit-palette
The model card declares the Apache License 2.0. Downloaded weights are excluded
from this repository.

The optional Tibetan ASR backend uses a private Monlam checkpoint solely for
Monlam-authorized internal evaluation. Neither the private source checkpoint nor
its converted Core ML weights are distributed by this repository or its public
builds. The preparation script requires an authenticated, authorized Hugging Face
account and an explicit internal-use acknowledgement.
